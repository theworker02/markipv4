# markipv4

Mark identifiers and ipv4 tokens for idempotent workflows.

**Site:** https://theworker02.github.io/markipv4/

## Install / run

```bash
git clone https://github.com/theworker02/markipv4.git
cd markipv4
node src/cli.js
node --test
```
